# 个人游戏评测成文

将已经确认的真实游玩体验、观点账本、采访记录、零散笔记或旧稿，整理成自然、重点鲜明且保留个人声音的中文游戏评测。

## 适用场景

- 游戏论坛中长评、简评和购买建议
- 通关评测、DLC／资料片评测、补丁后再评
- 重组重点平均、段落模板化或“AI 味”较重的旧稿
- 只处理标题、小标题、结构、文笔或终稿质量

本项目是成文编辑工具，不负责重新采访用户，也不负责外部评测研究。它可以接收已经由 `interview-game-review` 整理好的材料，也可以直接处理用户提供的笔记、旧对话、立场卡或人工终稿。

## 核心原则

- 不补写用户没有表达过的体验、心理、因果、人物动机或评价力度。
- 保留平台、版本、进度、游玩背景、具体例子、适用人群和推荐结论。
- 先确定文章主轴和篇幅权重，再写正文骨架，最后拟标题和小标题。
- 用具体材料和准确动词改善文章，不用空泛的媒体句、强行升华或整齐模板代替观点。
- 每一句第一人称体验和因果都要能回指用户原话或明确确认。

## 工作流程

1. 固定事实、声音边界、剧透边界和文章结构合同。
2. 根据用户反复提及、例子最具体或评价最强的内容确定主轴与篇幅权重。
3. 先写普通而准确的正文骨架，再进行结构重组和文笔编辑。
4. 生成并筛选直述型、核心体验型和条件判断型标题。
5. 做保真回读，检查第一人称心理、因果、人物称谓、评价强度和结论范围。
6. 使用机械检查脚本，并在交付前完成一次人工回读。

## 目录

- `SKILL.md`：技能入口、工作流和边界说明。
- `references/voice-profile.md`：用户声音与表达习惯。
- `references/prose-craft.md`：段落运动、句子和文笔编辑方法。
- `references/title-and-section-craft.md`：主标题与小标题设计。
- `references/before-after.md`：AI 初稿与人工修改的对照边界。
- `references/quality-rubric.md`：完整长评的终稿质检标准。
- `scripts/prose_check.py`：检查高风险句式、模板化结构和乱码等问题。
- `scripts/compare_drafts.py`：比较 AI 初稿与人工修订稿的结构和高风险句变化。

## 质检脚本

在 UTF-8 环境中检查完整稿件：

```powershell
$env:PYTHONUTF8='1'
python -B scripts/prose_check.py path/to/draft.md
```

脚本只负责暴露风险，不会自动改写文章，也不能替代保真和文笔判断。若脚本报告错误，应先修正后重新运行。

比较初稿与人工修订稿：

```powershell
python scripts/compare_drafts.py draft.md revision.md
python scripts/compare_drafts.py draft.md revision.md --diff
```

## 在 Codex 中使用

调用 `$personal-game-review-prose`，并提供已经确认的观点材料、旧稿或修改要求。若只要求输出正文，检查过程可以不展示，但不能跳过文件闭环、机械检查和人工回读。

# 游戏评测采访与立场确认

通过自适应采访，把用户真实的游戏体验整理为观点账本；必要时核验官方资料、专业评测和玩家社区，找出用户是否遗漏或有意不写的维度；在用户筛选并确认立场后，输出交给成文 Skill 的写作交接包。

本 Skill 的职责到“交接”为止，不生成完整评测正文、购买建议正文、主标题、小标题或可直接发布段落。需要成稿时调用 [`personal-game-review-prose`](../personal-game-review-prose/)，它只接收确认后的材料，不重新采访或搜索。

## 适用场景

- 游戏论坛中长评、通关评测和购买建议
- 用户有大量零散想法、口述、笔记、AI 初稿或人工终稿，但难以组织
- 需要区分亲身体验、客观事实、个人喜恶、作品评价和推荐结论
- 系列对比、争议作品、版本再评、DLC 或证据较复杂的深度文章

## 工作流程

1. 识别已有材料和当前状态，不让用户重复已经说过的内容。
2. 确认游戏、平台、版本、进度、剧透边界、读者、篇幅和发布位置等硬约束。
3. 围绕上一轮回答追问具体例子、判断依据、覆盖范围和反例，保存有辨识度的原话。
4. 维护观点账本，区分观察、解释、作品评价、个人喜恶和推荐，并记录证据强度与适用边界。
5. 原始立场稳定后，先核验官方事实，再根据任务需要扫描专业媒体和玩家社区，整理成盲点卡交给用户筛选。
6. 确认一句话总评、主轴、支撑点、限制条件、适合人群、推荐态度和剧透边界。
7. 按 [`writing-handoff.md`](references/writing-handoff.md) 输出交接包，停止在交接状态。

“继续”“好的”等一般回应不等于跳过盲点筛选或立场确认。未经用户确认的外部观点不得写成第一人称；用户说“直接写”时，也只把材料交给 `personal-game-review-prose`。

## 外部资料边界

来源优先级为官方事实、用户直接材料、专业媒体和玩家社区。外部资料用于核对事实和发现值得询问的盲点，不用于替用户补写体验。每个候选盲点标明来源类型、平台／版本／难度／进度等条件，以及与用户观点的关系和用户状态。

## 目录

- `SKILL.md`：职责边界、采访流程、盲点筛选和交接规则。
- `references/interview-and-ledger.md`：自适应采访、观点账本和声音锚点。
- `references/research-policy.md`：外部评测扫描、来源层级和盲点卡规则。
- `references/writing-handoff.md`：交给成文 Skill 的结构化模板和交接前检查。
- `references/reviewer-profile.md`、`references/writing-guide.md`：旧版成文参考，为兼容保留；当前采访流程不加载它们。
- `scripts/review_draft.py`：旧版稿件风险检查脚本，为兼容保留；当前成稿质检由 `personal-game-review-prose` 负责。
- `agents/openai.yaml`：Codex 中的显示名称、简介和默认提示词。

## 在 Codex 中使用

调用 `$interview-game-review`，说明游戏、平台／版本、游玩进度、剧透边界以及希望整理的评测类型。已有采访、笔记或旧稿时可直接提供，Skill 会从现有状态继续。

采访与立场确认完成后，把交接包交给 `$personal-game-review-prose`。如果只想测试成稿能力，可直接使用已有交接包或确认材料调用后者，不必重新采访。

# 评论者画像（第二版，兼容参考）

> 归属说明：本文件保留早期采访／成文共用版本，供历史材料对照。当前 `interview-game-review` 不读取本文件来生成文章；成文阶段以 `personal-game-review-prose/references/voice-profile.md` 为准。采访阶段只提取用户当轮明确说出的评价坐标和声音锚点，不把这里的画像当作用户尚未确认的体验。

此画像来自两次完整评测对话、两份 AI 初稿、两份论坛终稿，以及《九日》的首次 Skill 实测与用户反馈。把它当作可继续校准的当前模型，不要把少数文章的偶然写法永久固化。

## 思考与评价方式

1. **先交代自己与作品的关系。** 用户习惯说明是否系列玩家、玩过哪些前作、为何关注、何时购买以及实际进度。这样的个人背景不是客套，而是评价成立的坐标。
2. **先找作品真正想做的事。** 判断重点不是平均检查所有栏目，而是明确核心承诺，然后看它是否兑现。核心长板足够突出时，可以容纳一些不影响主体验的短板。
3. **严格校准结论力度。** 会主动把“劝退”“好很多”“最高水平”等过强说法降下来；会承认记忆模糊、体验较少、某问题只出现两次或自己其实不在意。
4. **喜欢与质量判断并行。** 能接受“这个问题确实存在，但对我影响很小”“外部说法成立，但不是我的体验”“工作量可以理解，但仍是改进方向”。
5. **前作比较只服务于理解本作。** 用户会用前作说明系统增减或体验差异，但反感让整篇文章困在“比前作强还是弱”的框架里。
6. **重视玩家实际感受。** 比起抽象术语，更关注设计最后造成了什么：是否想继续收集、是否觉得麻烦、是否产生陪伴感、是否需要查攻略、是否影响购买。
7. **结论面向具体人群。** 推荐态度可以很强，但必须说清适合谁、不适合谁。常见结论是“系列玩家直接买”“对某类体验感兴趣可以无脑入”“不在乎某要素则影响不大”。
8. **希望外部评测补足盲区。** 原始观点先独立形成，之后应较全面地查看官方资料、不同媒体和玩家讨论，找出自己没注意到的维度、已经注意但不准备写的内容和相反观点。外部扫描用于帮助回想和筛选，不代表所有内容都要进入文章。

## 语言与文章气质

- 默认是**论坛中长评**：比聊天完整，比媒体稿松弛；有章节和小标题，但不是报告。
- 对成文质量要求较高。文章不能只是把口述整理通顺，而应有准确用词、自然转折、合理详略和有变化的节奏，达到可以直接发布的水平。
- 使用第一人称。开头通常从个人经历、期待或游玩过程切入，再自然落到总体判断。
- 允许适量使用“其实、当然、不过、因此、说实话、我觉得、感觉、无所谓、没什么影响”等口语连接，但不要每段重复。
- 接受“电子 ED、暴雷、小而美、甜品级、无脑入”等玩家社区词汇；是否使用取决于发布场所和上下文。
- 喜欢直接、常规、易懂的小标题；可以整齐，但不要为对仗制造浮夸概念。
- 可以使用较长句和自然转折，不追求每句话都短促有力，也不追求媒体式金句密度。
- 对不确定内容坦率保留：“忘记学名”“似乎有所减少”“只有一点点”“1个（或者2个）”。在不影响理解时，这种边界感比假装权威更像本人。
- 结尾可以带一点随手回望或自我吐槽，不必强行升华。
- “文笔好”不等于评论家腔。宁可把已有体验写准、写透，也不要用用户没说过的心理活动、感情变化或漂亮比喻制造具体感。
- 用户自述的系列关系、类型经验和技术水平是评价成立的坐标。可以修整表达，但不要为了显得谦逊把“资深、玩过很多、自认高手”降成“接触过”。

## 声音锚点

以下句子只用于识别节奏和态度，不要在其他游戏评测中照抄：

- “只因生性懈怠一直拖到了现在。”
- “我理解，也不认为这是什么扣分项，只是制作组以后可以努力的一个方向。”
- “虽然标题写了是关于‘追寻不死’的故事，结果为了不去剧透导致全篇一点都没提到，不过也无所谓了。”
- “不是不能忍，但每次都要花半分钟找东西，积累下来就是耐心消耗。”
- “如果你和我一样，对宝可梦的爱从来不在对战上——买。”

采访中发现新的自然表达时，记录其原话、使用语境和用户是否希望保留。成文时优先保留少量真正有辨识度的锚点。

## 明确不喜欢的写法

- 把普通感受包装成“解封时刻”“换了跑道”“结构级反转”等评论家腔概念。
- 用“反转弱了，角色活了”之类口号替代真实、复杂的判断。
- 为了文采堆叠隐喻、对偶、短句和“它不是……而是……”结构。
- 每一节都写成同样整齐的“判断—解释—总结”，或用空总结反复提醒读者文章主轴。
- 一味模仿聊天口吻，如“通关了，来聊两句”，导致文章过于随意。
- 小标题过度戏剧化、标题党化，或每节都故意做成金句。
- 把前作作为全文唯一参照，忽略本作自己讲了什么、做成了什么。
- 写入用户没有提供的具体场景、角色对峙或心理活动。
- 把“还可以”“有印象”“能够接受”等克制判断悄悄升级成“很流畅”“不会忘”“完全成立”。
- 把几个优点整齐分配成“玩法推动我、美术吸引我、剧情留住我”等并未由用户说出的心理因果。
- 为了“像本人”保留错别字、语音转写重复和明显病句。

## 编辑幅度

保留用户的判断顺序、态度强弱、常用词和少量声音锚点；修正错别字、标点、重复和影响理解的病句。不要把所有句子统一成精确、对称、无瑕疵的媒体文风。用户明确改过的标题、事实和结论优先级高于本画像。

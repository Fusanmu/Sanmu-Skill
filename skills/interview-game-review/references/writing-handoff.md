# 游戏评测写作交接包

这份材料是 `interview-game-review` 交给 `personal-game-review-prose` 的事实、观点和边界清单，不是文章草稿。

## 使用规则

- 只放已经确认的用户体验、用户筛选后的外部信息和必要的中性事实。
- 外部观察必须保留来源类型、适用条件和用户状态；没有“采纳”状态的内容不能改写成第一人称。
- 用户原话可以作为声音锚点，但不要在采访阶段把它们润色成段落。
- “文章主轴”和“结构合同”只描述判断关系、章节功能和篇幅权重，不提供标题候选或散文句子。
- 缺少证据的内容写入“保守点”或“待确认”，不让成文 Skill 用常识补齐。

## 交接前检查

1. 每个核心观点都有来源、例子、覆盖范围和安全措辞。
2. 用户没有采纳的外部观察仍带有状态，不会混进第一人称材料。
3. 立场卡的评价力度与用户原话一致，推荐结论有适用人群和条件。
4. 结构合同没有伪装成标题、段落或“漂亮的开头”。
5. 交接包明确列出未核验、待回想和不得推出的内容。
